# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.x     | Latest release only |

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/seifreed/MispFleet/security/advisories/new).
Do not open public issues for security reports.

You will receive an acknowledgement within 7 days. We aim to provide an initial
assessment within 14 days and to release a fix for confirmed issues as soon as
practical, coordinating the disclosure date with the reporter.

## Disclosure policy

We follow coordinated disclosure: details are published after a fix is available,
crediting the reporter unless anonymity is requested.

## Scope exclusions

- Vulnerabilities in MISP itself (report to the MISP project).
- Issues requiring a compromised local machine or already-leaked API keys.
- Denial of service against MISP servers caused by user-supplied configuration.
